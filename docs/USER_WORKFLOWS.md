# FileForge User Workflows & Journey Specifications

## Universal 4-Step Journey
1. **Discover & Select**: User chooses a tool from the categorized directory or searches for an operation.
2. **Upload & Inspect**: Drag-and-drop or file picker accepts files. Real-time file cards show name, size, page count, and order.
3. **Configure Settings**: Contextual sidebar exposes tool-specific controls (e.g. compression level, watermark position, password, page ranges).
4. **Process & Retrieve**: Genuine processing with real progress state. Download button, file size savings comparison, QR code share, and "Continue to next tool" workflow action.

## Multi-Tool Workflows
Users can assemble custom automation pipelines, such as:
1. `Merge` multiple contract drafts.
2. `Compress` output for email distribution.
3. `Watermark` with "CONFIDENTIAL" draft overlay.
4. `Protect` with password encryption.
The workflow engine passes the intermediate buffer to each sequential stage seamlessly.
